# 可用工具目录 Skill

## 用途

展示当前统一 Agent Function Calling 注册表中的全部工具和 Skill。
目录包括知识库检索工具、本地 Skill，以及已注册的远程 MCP Skill。

## 适用场景

- 用户问「列出你的工具」
- 用户问「你有什么技能」
- 用户问「有哪些可用能力」或「工具注册表里有什么」

## 返回结构

- `summary.tool_count`：当前可用工具总数
- `summary.categories`：按类别统计的工具数量
- `tools`：工具名称、用途、类别、来源、提供方、注册位置和 Function Calling 参数结构

## 回答规范

- 用清晰的列表介绍工具名称和主要用途。
- 可以按类别分组，但不要逐字复述完整 JSON Schema。
- 明确说明知识库检索也是可用工具之一。
- 只展示当前注册表实际返回的工具，不要编造未注册能力。
