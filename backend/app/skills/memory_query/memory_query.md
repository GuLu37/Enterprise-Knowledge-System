# 记忆查询 Skill

## 适用场景

当用户询问“你记得什么”“我之前说过什么”“我的偏好是什么”或某个个人事实是否被记住时使用本 Skill。

## 执行目标

查询当前登录用户自己的画像记忆和长期事件记忆，不能跨用户读取或展示记忆。

## 调用参数

- `query`：可选。用于语义检索长期事件记忆。
- `top_k`：可选。最多返回多少条记忆，默认 `5`。
- `memory_scope`：可选，可取 `all`、`profile` 或 `event`。

## Function Calling

调用统一技能接口：

```json
{
  "name": "memory_query",
  "arguments": {
    "query": "用户想查询的记忆内容",
    "top_k": 5,
    "memory_scope": "all"
  }
}
```

## 返回结果

- `profile_memories`：稳定的用户画像事实。
- `matched_memories`：按语义召回的长期事件记忆。
- `summary`：画像记忆和匹配记忆的数量统计。

## 使用规则

- 只使用当前登录用户的记忆上下文。
- 没有查到记忆时，明确说明当前没有查到已保存的信息。
- 记忆内容只能作为参考，不能把不确定记忆表述成确定事实。
- 用户要求删除或修改记忆时，使用现有记忆管理流程，不要把查询结果当作删除确认。
- 用户询问文档内容时，改用主检索流程或 `document_hot_word_statistics`。
