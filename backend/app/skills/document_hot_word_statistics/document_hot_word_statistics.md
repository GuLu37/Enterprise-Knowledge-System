# 文档热词统计 Skill

## 适用场景

当用户询问某个具体文件中出现频率最高的词、热词或关键词时使用本 Skill。

用户通常会提供文件名，也可能提供文档 ID。

## 执行目标

先根据文件名或文档 ID 定位目标文档，再统计该文档内容中实际出现频率最高的词，并按频率从高到低返回结果。

## 调用参数

- `file_name`：可选。按原始文件名或系统存储文件名模糊匹配。
- `document_ids`：可选。按文档 ID 精确筛选。
- `top_k`：可选。返回前多少个热词，默认 `10`。
- `include_samples`：可选。是否返回匹配文档摘要，默认 `true`。

## Function Calling

调用统一技能接口：

```json
{
  "name": "document_hot_word_statistics",
  "arguments": {
    "file_name": "目标文件名",
    "top_k": 10
  }
}
```

## 返回结果

- `top_words`：热词列表，包含 `term`、`document_count` 和示例文档。
- `summary`：匹配到的文档数和 chunk 数。
- `filters`：实际使用的筛选条件。

## 使用规则

- 用户明确提到文件名时，优先使用 `file_name`，不要统计整个文档库。
- 如果文件名匹配到多个文档，保留返回结果中的多个匹配文档，并向用户说明统计范围。
- 只报告统计结果，不要把热词自动解释成用户意图或业务结论。
- 用户询问文档正文、制度内容或具体事实时，使用主检索流程，不要只依赖本 Skill。
- 用户询问记忆或个人画像时，改用 `memory_query`。
