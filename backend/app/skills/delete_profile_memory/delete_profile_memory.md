# 删除个性化记忆 Skill

## 适用场景

当用户明确要求删除、遗忘、清除、撤回自己的某条个性化记忆（如名字、偏好、地点、习惯、联系方式等画像信息）时使用本 Skill。

典型表达：删除我的偏好、忘掉关于北京的记忆、把记的名字删掉、清除我的画像信息。

## 执行目标

按用户指定的条件，删除当前登录用户自己的个性化记忆。不能跨用户删除，也不能删除事件记忆以外的其他数据。

## 调用参数

- `memory_keys`：可选。精确删除的 memory_key 列表，如 `["profile.location"]`、`["profile.name"]`。
- `keywords`：可选。按内容关键词模糊匹配要删除的记忆，如 `["北京"]`。会匹配 memory_key 和记忆内容。
- `max_deletes`：可选。单次最多删除条数，默认 `50`。匹配数超过上限时会拒绝执行，要求更精确条件，防止误删。

`memory_keys` 与 `keywords` 至少提供其一；两者同时提供时按并集匹配。

## Function Calling

调用统一技能接口：

```json
{
  "name": "delete_profile_memory",
  "arguments": {
    "memory_keys": ["profile.location"],
    "keywords": ["北京"]
  }
}
```

## 返回结果

- `deleted_count`：实际删除条数。
- `matched`：被删除记忆的摘要列表（memory_key、内容、置信度）。
- `summary`：执行结果说明（成功 / 无匹配 / 超上限 / 缺条件）。

## 使用规则

- 只在用户主动、明确要求删除记忆时调用，不能擅自删除。
- 用户表达模糊时，先用 `memory_query` 查询出候选记忆，再让用户确认要删哪条，避免误删。
- 删除是软删除：被删记忆立即不再参与召回，历史版本保留用于追溯。
- 删除操作只针对当前登录用户，不能删除其他用户的记忆。
